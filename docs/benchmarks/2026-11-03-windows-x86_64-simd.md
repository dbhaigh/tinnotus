# AudioEngine SIMD Benchmark Comparison

- Generated: 2026-11-03
- Platform: Windows (x86_64)
- CPU: AMD Ryzen AI 9 HX 370 w/ Radeon 890M
- Compiler: Microsoft Visual C++ 19.52, Release
- Scalar baseline: [full 450-case report](./2026-11-03-windows-x86_64-msvc.md)
- Default engine path: SSE2; AVX2 was measured separately with `/arch:AVX2`.
- Benchmark thread: pinned to logical processor 0.

Each run covered the full 450-case matrix with 300 warm-up blocks, 6,000 latency samples, and three throughput passes of at least 50 ms. The table summarizes the 36 hot cases at 48 kHz: 2/4/6/8 channels, 2/4/8 active notches, and 128/256/512-frame blocks. Values are geometric-mean throughput ratios against the scalar baseline; the value in parentheses is the median case ratio.

| Channels | Default SSE2 vs scalar | AVX2 vs scalar | AVX2 vs SSE2 |
|---:|---:|---:|---:|
| 2 | 1.009x (1.006x) | 1.023x (1.025x) | 1.014x (1.018x) |
| 4 | 1.139x (0.965x) | 0.988x (1.000x) | 0.867x (1.045x) |
| 6 | 1.398x (1.415x) | 1.467x (1.456x) | 1.050x (1.029x) |
| 8 | 1.796x (1.793x) | 1.729x (1.739x) | 0.963x (0.969x) |
| All hot cases | 1.303x (1.394x) | 1.265x (1.243x) | 0.971x (1.021x) |

The 2- and 4-channel layouts use the scalar implementation. Their results are near baseline overall, but individual cases are noisy; in particular, a 4-channel outlier shifts the SSE2 geometric mean away from its median. The clearest gains are at six and eight channels: default SSE2 measured 1.40x and 1.80x, respectively. AVX2 was not consistently faster than SSE2 on this CPU, so SSE2 remains the default.

All output checksums matched the scalar baseline exactly across all 450 configurations for both optimized builds. The SIMD/reference unit test also checks split-block processing for 1, 2, 4, 5, 6, 7, and 8 channels with eight active notches.

AVX2 remains opt-in via `TINNOTUS_ENABLE_AVX2`; the resulting binary requires an AVX2-capable CPU because dispatch is compile-time only. These measurements are specific to this machine and compiler, and small differences should not be treated as universal.
